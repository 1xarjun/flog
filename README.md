[Live](https://1xflog.vercel.app)
</div>

### Features:
- create posts with rich text content (via tiptap editor)
- share post with a link
- view shared post through shared link
- reply to a post
- upvote/downvote any post
- profile customization

### Motivation:

I always wanted to make a forum but making a forum from scratch is really time taking and kind of hard to get everything right. So i made just the barebones of a forum, a thread;
